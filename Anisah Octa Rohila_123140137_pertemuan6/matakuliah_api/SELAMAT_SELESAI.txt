## 🚀 Cara Menjalankan (Simpel!)

### 1. Setup (5 minutes)
```powershell
cd matakuliah_api
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python add_initial_data.py
```

### 2. Run Server
```powershell
python run_server.py
```

Server akan berjalan di: **http://localhost:6543**

### 3. Test API
```powershell
# Terminal baru dengan venv aktif
curl -X GET http://localhost:6543/api/matakuliah
```

## 📡 API Endpoints Ready to Test

### Get All Matakuliah
```bash
curl -X GET http://localhost:6543/api/matakuliah
```

### Create New Matakuliah
```bash
curl -X POST http://localhost:6543/api/matakuliah \
  -H "Content-Type: application/json" \
  -d '{"kode_mk":"IF201","nama_mk":"Jaringan Komputer","sks":3,"semester":5}'
```

### Update Matakuliah
```bash
curl -X PUT http://localhost:6543/api/matakuliah/1 \
  -H "Content-Type: application/json" \
  -d '{"nama_mk":"Algoritma Lanjut","sks":4}'
```

### Delete Matakuliah
```bash
curl -X DELETE http://localhost:6543/api/matakuliah/6
```
